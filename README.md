# 长江雨课堂习题助手

为 macOS 微信「长江雨课堂」小程序编写。默认监视「人工智能精通I」的本节课堂习题。等待阶段在本机运行，每五秒读取一次指定微信窗口，通过 WindowServer 核对微信窗口编号，使用 macOS 窗口截图、色彩采样和 Apple Vision 中文 OCR。程序将窗口不可读、课堂列表无匹配、发现待答题分别记录。

在另一台 Mac 上部署时，可复制[给新电脑 Agent 的提示词](AGENT_PROMPT.md)。

## 运行

需要 macOS 14 或更高版本、Xcode 命令行工具、Python 3.10 或更高版本。自动作答使用已登录的 Codex CLI。将实时课堂切到「习题」标签，保持正常大小，允许终端或宿主应用录屏和使用辅助功能。

```sh
make
python3 assistant.py --course '人工智能精通I' --lesson '2026-11-24-1825' --minutes 150
```

每节课使用唯一的 lesson 标识。同一节课重启时复用该标识，以便读取提交记录。默认运行上限为 180 分钟，可通过参数调整。程序在识别到明确的下课提示或达到时限时退出。前台运行可用 Ctrl-C 停止。加上 `--detect-only` 可只做检测。

## 窗口和异常恢复

监视中发现台前调度缩略图或最小化窗口时，程序自动前置微信、恢复「长江雨课堂」窗口。恢复可能短暂切换当前使用的应用。程序随后重新识别指定课程标题和课堂标签，成功时记录 `recovered` 并继续处理待答题。

故障持续时，自动作答模式调用 Codex 诊断。恢复 agent 可选择窗口中实际出现的重试、重新连接、目标课程和课堂入口，或在已确认的空白页尝试小程序的刷新菜单。无窗口截图时仅提供错误信息。持续故障会延长重试间隔。微信需要本人登录、系统权限缺失或找不到小程序入口时，可在日志中查看原因；程序继续检查。只检测模式使用本地窗口恢复。

## 作答和运行记录

颜色筛选先查找饱和蓝色横条，再在同一卡片内核对「课堂习题」「未完成」和页码。检测到待答题后尝试恢复微信课堂窗口，重新读取卡片，定位题面。课程标题和每张蓝色卡片分别裁切识别；当课件与习题页码相同时，程序点击已识别的卡片。每次需要判断下一步答题操作时，程序将该题当前窗口截图和 OCR 交给 Codex CLI，会消耗所用账户的模型额度。支持点击选项、输入文字、提交及确认。答题控件需出现在当前窗口可见范围内。遮挡、缩略图、题目未完整显示或提交回执不清晰都可能影响自动完成。

点击前复查窗口身份、当前画面与点击区域。提交前将页码写入 `.run/` 下的本节课记录，重启后据此跳过重复提交。因此提交时断线也可能留下尝试记录，是否完成应以平台回执为准。程序用 `verified` 记录已核实的回执，其他情况写入 `result` 或 `unavailable`。最新现场检测时间、状态和监视进程 PID 可在 `.run/status.json` 查看。运行日志依次以 `pending`、`opened`、`answer_action` 和 `verified` 标记发现卡片、打开对应题面、执行操作和核实回执。终端输出为 JSON Lines，可重定向到本地文件。运行时截图位于临时目录，进程正常结束时清理。

## 检查

```sh
python3 -m unittest -v
.build/rainwatch check
.build/rainwatch inspect
.build/rainwatch check '人工智能精通I' '/path/to/classroom-window.png'
```

离线图片应裁切到整个小程序窗口，包含课程标题和习题卡片。单元测试使用模拟窗口和模型返回值，验证去重记录、提交流程和卡片消失后的处理。
